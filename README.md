#📋 Sobre o Projeto

Este projeto simula o funcionamento de uma lâmpada que pode ser ligada e desligada através de um botão.

Ao clicar no interruptor:

A lâmpada muda de apagada 🌑 para acesa 💡.
A mensagem informativa é atualizada.
O texto do botão muda entre Ligar e Desligar.
A cor do fundo da página é alterada para representar a iluminação do ambiente.

🚀 Tecnologias Utilizadas
HTML5
CSS3
JavaScript (ES6)
